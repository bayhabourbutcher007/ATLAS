# ATLAS Principles

These are the permanent rules that every future ATLAS feature must follow. Before any work begins, ask:

**“Does this belong in ATLAS?”**

If the answer is **no** to any of the following, the feature must be revised or rejected.

---

## Decision‑First Design
Every surface must help the user make a better decision—not just display data.  
*Test*: Does the feature surface a clear insight or recommended next step tied to the user’s current context?

## Context Before Action
Never suggest a task without explaining why it matters now within the user’s whole life.  
*Test*: Can the user immediately see the connection between the suggested action and their broader goals, stressors, or resources?

## Friction Reduction
If logging or interacting feels like work, the feature fails. Input should be passive (calendar sync, bank API) or feel as effortless as a quick journal entry.  
*Test*: Does the user need to interrupt their flow or perform multiple steps to provide data?

## Anti‑Overwhelm
One screen, one insight, one next step. If understanding the value requires more than three taps, simplify.  
*Test*: Can a new user grasp the core value in a single glance?

## Growth Over Grading
Celebrate improvement in decision quality and personal learning velocity—not arbitrary completion metrics.  
*Test*: Does the feature reward learning from mistakes and showing progress over time?

## Privacy Ownership
No data ever leaves the user’s device without explicit, informed consent. Users must be able to delete their entire history with one tap, instantly.  
*Test*: Is data export or deletion under the user’s full control, with no hidden collection?

## Long‑Term Relevance
Avoid tech‑specific fads (blockchain, AI coach avatars, etc.). Favor timeless UI—clear typography, ample whitespace, calm colors—and interactions that would feel intuitive a decade from now.  
*Test*: Would this feature still make sense and be usable if rebuilt with tomorrow’s standard tools?

## Calm and Living Interface
The UI should feel like a quiet mission‑control center: soft, neutral palette with a single purposeful accent, humanist serif typography, generative textures that suggest life’s flow, and slow, physics‑based motions. Tone of voice is warm, precise, never patronizing.  
*Test*: Does using the feature leave the user feeling calmer and more in control, not more anxious or distracted?

---

These principles act as a filter. If a proposal fails any test, it does not belong in ATLAS.
